## Recreate a video with MiniMax M3.1 Flash

Every video page on [SandBase Lab](https://www.sandbase.ai/lab/ai-videos/minimax-m3-1-flash?utm_source=github&utm_medium=readme&utm_campaign=awesome-minimax-m3-1-flash&utm_content=recreate) has a **Recreate** button: it sends the post to M3.1 Flash in the Lab text arena and returns the code, ready to play in the browser.

With the API, MiniMax M3.1 Flash is `minimax/minimax-m3.1-flash` on SandBase (OpenAI-compatible); the id has served M3.1 Flash since it shipped on October 19, 2026. Put a prompt in `prompt.txt`, create a key in the [console](https://www.sandbase.ai/console/keys?utm_source=github&utm_medium=readme&utm_campaign=awesome-minimax-m3-1-flash), and run:

```bash
jq -n --rawfile prompt prompt.txt \
  '{model: "minimax/minimax-m3.1-flash", max_tokens: 128000, messages: [{role: "user", content: $prompt}]}' |
curl -sS --max-time 900 https://api.sandbase.ai/v1/chat/completions \
  -H "Authorization: Bearer $SANDBASE_API_KEY" \
  -H "Content-Type: application/json" \
  -d @- | jq -r '.choices[0].message.content' | sed '/^```/d' > minimax.html
```

Open `minimax.html` in a browser, or run it in a [SandBase Sandbox](https://www.sandbase.ai/landing/sandbox?utm_source=github&utm_medium=readme&utm_campaign=awesome-minimax-m3-1-flash) to keep generated code isolated. Thinking is always on for this model, and the hidden reasoning tokens come out of `max_tokens`, so the call above asks for 128,000. Full walkthrough: [tutorial](docs/tutorial.md). Pricing: [model page](https://www.sandbase.ai/model/minimax/minimax-m3.1-flash?utm_source=github&utm_medium=readme&utm_campaign=awesome-minimax-m3-1-flash).

## FAQ

### What is MiniMax M3.1 Flash?

MiniMax-M3.1-Flash is the fast, cost-efficient tier of MiniMax's M3.1 generation, released on October 19, 2026. It accepts text, image and video input, has a 1,000,000-token context window and up to 512,000 output tokens, and thinking is always on, with reasoning effort from `low` to `max`. MiniMax says it is 3x faster and about a third of the price of M3, and SandBase's model card calls it open-weight. On SandBase it is `minimax/minimax-m3.1-flash`. Source: `sandbase inspect minimax/minimax-m3.1-flash`.

### How are these MiniMax M3.1 Flash videos made?

The model doesn't render video. It writes a web page (HTML with Three.js, WebGPU, Canvas or SVG), and the creator records the page playing. Several creators ran it inside MiniMax Code, which also generates images and music for the page, and a few let it drive a coding harness. See the [tutorial](docs/tutorial.md).

### Where do I find the prompt for a video?

Videos tagged **prompt** come with the creator's prompt on their Lab page. The [prompt index](docs/prompts.md) lists all of them.

### How do I write a good MiniMax M3.1 Flash prompt?

Name one self-contained HTML file and the renderer you want (Three.js, WebGPU, Canvas or SVG), describe the scene, the controls and the state a recording should catch, ban external assets, and ask it to test its own page. Leave a large `max_tokens`: thinking is always on and shares that budget. Details and a template: [prompt guide](docs/prompt-guide.md).

### How do I use the MiniMax M3.1 Flash API?

On SandBase the model id is `minimax/minimax-m3.1-flash` on the OpenAI-compatible `/v1/chat/completions` endpoint. One key works for every model, and `reasoning_effort` takes `low`, `medium`, `high`, `xhigh` or `max`. See [Recreate](#recreate) and the [model page](https://www.sandbase.ai/model/minimax/minimax-m3.1-flash?utm_source=github&utm_medium=readme&utm_campaign=awesome-minimax-m3-1-flash).

### Is MiniMax M3.1 Flash better than DeepSeek V4.1 Flash 1017, Claude Opus 5.5 or Gemini 4 Argon?

Creators mostly ran it against DeepSeek, and they disagree. On price M3.1 Flash usually wins: $0.21 against $0.38 for the same submarine scene, $0.22 against $0.54 for a pixel city, $0.50 against $1.15 on one prompt, and $0.014 against $1.22 for Claude Opus on a landing page. On quality it is split — several creators preferred its design work or its pelican, while others found DeepSeek's prompt adherence and detail better, and one called it the weakest of four on a Roadster drive. There is no measured answer yet: the Lab [Evals boards](https://www.sandbase.ai/lab/evals?utm_source=github&utm_medium=readme&utm_campaign=awesome-minimax-m3-1-flash) (Artificial Analysis, snapshot 2026-10-19) have no MiniMax M3.1 Flash row, so the Lab [Pelican Test](https://www.sandbase.ai/lab/pelican-test?utm_source=github&utm_medium=readme&utm_campaign=awesome-minimax-m3-1-flash) is the only measured result — 3.25, rank 6 of 22, at about $0.006 a drawing. Details: [model comparison](docs/model-comparison.md).

### How much does one video cost?

Creators report from $0.014 (a hardware landing page) and $0.029 (one benchmark task) up to $2.34 (a Tesla Roadster chase scene), with most one-shot pages between $0.02 and $0.70. The list price on SandBase is $0.15 per million input tokens and $0.60 per million output tokens, and reasoning tokens bill as output.
